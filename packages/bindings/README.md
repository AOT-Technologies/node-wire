# node-wire-bindings

The MCP host for [Node Wire](https://github.com/AOT-Technologies/node-wire) connectors. It reads
`config/connectors.yaml`, builds the installed connectors, and exposes their actions as MCP tools
over stdio or Streamable HTTP. Node Wire's per-connector MCP images and the servers generated by
`nw gen-all` / `nw gen-mcp` run on this package.

Most users get it as a dependency of an image or a generated server. Install it directly to host
Node Wire connectors in your own MCP server process.

## What it provides

| Module | What you get |
|---|---|
| `bindings.factory` | `ConnectorFactory`: loads `config/connectors.yaml`, resolves secrets and auth, and returns tenant-pinned connector instances |
| `bindings.invoke` | `invoke()`: runs one connector action for a resolved tenant and config, checking that the connector is exposed on that protocol |
| `bindings.mcp_server` | `McpServer`: the MCP server, with bearer-token auth (API key or JWT), scope policy, tenant and config selection tools, and an optional tool-search mode |

The REST and gRPC hosts are not in this package. They ship only with the Node Wire repository.

## Install

```bash
pip install node-wire-bindings
```

This pulls in [`node-wire-runtime`](https://pypi.org/project/node-wire-runtime/) and the
[MCP Python SDK](https://pypi.org/project/mcp/). Install the connectors you want to serve
separately, or all of them with [`node-wire-connectors`](https://pypi.org/project/node-wire-connectors/).
Pre-releases are published as `X.Y.ZbN`; install one with `pip install --pre node-wire-bindings`.

Wheels are compiled with Cython and contain no Python source. They are built for CPython 3.11,
3.12 and 3.13 on Linux x86_64 (manylinux and musllinux), macOS arm64 and Windows x64.

## Usage

```python
from bindings.mcp_server.server import McpServer

server = McpServer(server_name="my-connectors")
server.run("stdio")  # or "streamable-http"
```

`McpServer` serves every connector that is listed in `NW_ALLOWED_CONNECTORS` and enabled for
`mcp` in `config/connectors.yaml` (set `NW_CONFIG_PATH` to read it from elsewhere). Pass
`connector_ids=[...]` to serve fewer.

| Variable | Purpose |
|---|---|
| `NW_ALLOWED_CONNECTORS` | Comma-separated connector IDs to load |
| `NW_CONFIG_PATH` | Path to `connectors.yaml` |
| `NW_MCP_API_KEY` / `NW_MCP_JWT_SECRET` | Credentials MCP clients must present. Without either, the server refuses calls unless `NW_MCP_AUTH_DISABLED=true` |
| `NW_MCP_API_KEY_SCOPES` | Scopes granted to the API key, e.g. `mcp:http_generic.request`. A caller sees and runs only the tools its scopes cover |
| `NW_MCP_SCOPE_POLICY_DEFAULT` | `deny` (default) requires a scope per tool; `allow` lets through any tool with no explicit scope mapping. With `deny` and no scopes, `tools/list` is empty |
| `NW_MCP_HOST`, `NW_MCP_PORT`, `NW_MCP_PATH` | Bind address and path for `streamable-http` |
| `NW_MCP_TOOL_MODE` | `list` (default) advertises every tool; `search` advertises `nw_search_tools` and `nw_call_tool` instead |
