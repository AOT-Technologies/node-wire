# node-wire-toolhive

Runs a node-wire connector inside an MCP server generated by `nw gen-stacklok` (stacklok
mcp-builder + node-wire runtime), deployed behind [ToolHive](https://github.com/stacklok/toolhive).

- **Credential relay** — ToolHive forwards the upstream credential as `Authorization: Bearer`;
  `RelayAuthProvider` presents it the way the connector's auth block expects (bearer, named
  header, or query parameter), re-read on every call. Opt-in per connector via
  `NW_UPSTREAM_BEARER_CONNECTORS`.
- **Tenant** — resolved from the `X-Tenant-ID` header each ToolHive tenant proxy injects
  (`NW_MULTITENANCY_ENABLED=true`).
- **Config tools** — `nw_list_configs` / `nw_select_config` choose a named config per MCP session.
- **Execution** — `NodeWireClient.run(action, arguments)` runs through the node-wire runtime
  (validation, policy hook, retries, circuit breaker, error taxonomy, telemetry).
